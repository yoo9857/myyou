# 영화 리뷰 엔진 연동 감사

## 판정

상태: `설계 단계 정상 / 제작 단계 의도적 차단`

현재 콘스탄틴 스토리맵은 도입부만 작성된 `draft`다. 따라서 편집표 재생성, 나레이션 생성, FFmpeg 렌더, CapCut 프로젝트 생성이 모두 차단되어야 하며 실제 테스트에서도 차단됐다.

## 통과한 검사

- Python 컴파일: `pipeline.py`, `narration_pass.py`, 콘스탄틴 빌더, CapCut 생성기, 스토리맵 검사기
- 스킬 구조 검사: `Skill is valid`
- 현재 30개 기존 편집표 역호환 검증: 통과
- 스토리맵 초안 구조 검증: 통과
- 미래 화면을 먼저 말하는 합성 실패 케이스: `FUTURE_LEAK` 검출
- 필수 사건이 편집표에서 빠진 합성 실패 케이스: `STORY_EVENT_OMITTED` 검출
- draft 렌더 차단: exit 1
- draft 나레이션 생성 차단: exit 1
- draft CapCut 생성 차단: exit 1, 테스트 프로젝트 폴더 미생성
- 프로젝트 설정 템플릿 JSON 파싱: 통과

## 이번에 복구한 연동

- `pipeline.py plan/render`가 스토리맵 승인 검사를 실제 호출한다.
- 나레이션 패스와 콘스탄틴 수동 빌더도 같은 게이트를 통과해야 한다.
- CapCut 생성기도 승인된 스토리맵과 자막 트랙 개수 일치를 확인한다.
- 편집표 생성 프롬프트의 고정 4~12초 샘플링과 나레이션 55~65% 강제 규칙을 제거했다.
- 나레이션 후보 85~100% 유지 규칙을 제거했다.
- 편집표 생성 시 인과 스토리맵을 모델 입력에 포함한다.
- 승인된 스토리맵의 `must_show` 구간이 편집표에서 빠지면 렌더 전에 실패한다.
- CapCut 하드링크 실패 시 파일 복사로 대체한다.
- 독립 실행 스크립트의 긴 traceback을 간결한 게이트 오류로 교체했다.

## 아직 남은 필수 작업

1. 콘스탄틴 스토리맵은 도입부 한 구간뿐이다. 중반·후반 사건 그래프가 작성되기 전에는 승인할 수 없다.
2. 도입부 사건 중 5개에 `transition_in` 판정이 아직 없다.
3. `build_constantine_story_v3.py`의 수동 `BLOCKS`는 스토리맵에서 자동 파생되지 않는다. 현재는 게이트와 사후 누락 검사로만 보호된다.
4. CapCut 생성기는 아직 Constantine과 CapCut 9.1 템플릿 구조에 묶여 있다. 범용 어댑터 분리가 필요하다.
5. “다음 대사 반복”, “근거 없는 주제 해석”, “감정 장면 침범”은 의미 판단이 필요해 정적 검사만으로 완전 자동화되지 않았다.
6. 장르별 프로필, 회귀 테스트 모음, 자동화된 CI는 아직 구현되지 않았다.
7. 기존 V3/V4 CapCut 프로젝트는 엔진 완성 전의 미리보기이며 승인된 최종 산출물이 아니다.

## 다음 안전 단계

렌더를 다시 실행하지 말고 콘스탄틴 중반부 사건 그래프를 한 구간씩 작성한다. 각 구간에서 원인, 필수 장면, 감정적 동기, 공개 시점, 전환 방식을 확정한 뒤 승인 상태를 갱신한다.
