# Constantine 스토리 흐름 설계서

## 편집 원칙

1. 원인 장면을 보여주기 전에 결과를 설명하지 않는다.
2. 핵심 사건은 나레이션으로 대체하지 않고 영화 장면과 원대사로 보여준다.
3. 나레이션은 시간·장소·목적을 연결하거나, 이미 드러난 사실의 의미만 정리한다.
4. 한 구간의 인과가 완성된 뒤에만 다음 구간을 설계한다.
5. 전체 프록시는 모든 구간이 확정된 뒤 한 번만 만든다.

## 영화 전체를 끌고 갈 세 축

- 외부 사건: 지옥의 존재들이 규칙을 깨고 인간 세계로 넘어오려 한다.
- 콘스탄틴: 죽음을 앞둔 남자가 구원을 거래처럼 얻으려 한다.
- 안젤라: 동생의 죽음을 부정하던 형사가 자신이 외면한 세계를 받아들인다.

이 세 축이 따로 진행되다가 안젤라가 콘스탄틴을 찾아오면서 하나의 이야기로 합쳐져야 한다.

## 1구간 — 도입과 두 주인공의 상처

목표 분량: 편집본 약 0:00~6:35

### 1. 숙명의 창 발견

- 원본 후보: 01:38~02:30
- 기능: 설명되지 않은 불길한 물건과 초자연적 이상을 먼저 보여주는 훅.
- 반드시 보여줄 것: 창 발견 → 남자의 이상 반응 → 차 사고와 비정상적인 회복.
- 나레이션: 창을 발견하는 현재 행동까지만. 사고와 회복은 절대 먼저 말하지 않는다.
- 목표 편집 길이: 40~50초.

### 2. 콘스탄틴의 첫 퇴마

- 원본 후보: 04:29~08:26
- 기능: 주인공, 직업, 세계의 규칙을 행동으로 소개.
- 반드시 보여줄 것: 소녀 확인 → 거울을 이용한 퇴마 → 악령이 인간 세계로 나오려 한 이상 징후.
- 나레이션: 방에 들어서는 콘스탄틴을 소개하는 한 블록만 사용.
- 보존할 것: 퇴마 도구의 준비, 거울 속 악령, “보스에게 안부 전해” 대사와 장면의 결말.
- 목표 편집 길이: 110~125초.

### 3. 안젤라의 고해

- 원본 후보: 11:39~12:53
- 기능: 안젤라가 남들이 보지 못하는 것을 감지하지만 스스로 부정하고 있다는 사실을 소개.
- 반드시 보여줄 것: 사람을 너무 정확히 알아보는 자신의 감각을 두려워하는 고백, 이사벨을 떠올리는 순간.
- 나레이션: 새로운 인물과 장소를 알리는 짧은 전환 브리지만 허용.
- 목표 편집 길이: 40~50초.

### 4. 이사벨의 탈출과 추락

- 원본 후보: 12:52~14:20
- 기능: 안젤라가 사건을 끝까지 파고들 수밖에 없는 감정적 원인.
- 반드시 보여줄 것: 병실에서 깨어난 이사벨 → 옥상으로 향함 → 망설임 → 추락.
- 나레이션: 사용하지 않는다. 음악, 호흡, 환경음과 화면으로 공감대를 만든다.
- 금지: 추락이나 죽음을 장면보다 먼저 말하는 것.
- 목표 편집 길이: 55~65초.

### 5. 콘스탄틴의 검사 결과

- 원본 후보: 14:39~15:32
- 기능: 외부의 악마 사건과 별개로 주인공 개인에게도 시간이 없다는 압박을 부여.
- 나레이션: 병원 전경에서 장소 전환만 안내. 폐암과 남은 시간은 의사의 원대사로 공개.
- 보존할 것: 콘스탄틴이 살려달라고 하는 순간, 의사의 냉정한 진단, 이미 갈 곳이 정해졌다는 대사.
- 목표 편집 길이: 35~45초.

### 6. 안젤라의 부정

- 원본 후보: 15:38~17:05
- 기능: 이사벨의 추락을 본 관객과 자살을 인정하지 않는 안젤라 사이에 감정적 긴장을 형성.
- 나레이션: 사용하지 않는다.
- 보존할 것: 이사벨은 절대 자살하지 않았다는 안젤라의 확신과 주변 인물들의 반응.
- 목표 편집 길이: 45~55초.

### 7. 규칙이 깨졌다는 단서

- 원본 후보: 18:51~19:50
- 기능: 첫 퇴마의 이상과 더 큰 사건을 연결하고 비먼을 소개.
- 나레이션: 콘스탄틴이 이상을 확인하기 위해 비먼을 찾았다는 인과만 연결.
- 보존할 것: 악령이 인간을 통로로 삼는 전례는 없다는 원대사.
- 목표 편집 길이: 40~50초.

## 1구간 종료 조건

- 관객은 이사벨의 죽음을 직접 목격했다.
- 안젤라가 왜 자살을 믿지 않는지 감정적으로 이해한다.
- 콘스탄틴에게 남은 시간이 짧다는 사실을 원대사로 알게 된다.
- 첫 퇴마의 이상이 단독 사건이 아니라는 의문이 남는다.
- 이 네 조건이 충족되기 전에는 중반부 편집표를 수정하지 않는다.

## 다음 설계 구간

안젤라의 의뢰 → 미드나이트의 중립지대 → 직접 공격 → 이사벨의 지옥 확인까지를 하나의 추적 구간으로 설계한다.
