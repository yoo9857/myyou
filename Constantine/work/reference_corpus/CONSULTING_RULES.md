# Constantine V3 영화리뷰 편집 컨설팅

## 분석 표본

- movie trip 무비트립: 사용자 지정 기준 영상
- 지무비: 오컬트 영화 리뷰
- 고몽: 드라마 영화 리뷰
- B Man 삐맨: 판타지·악마 영화 리뷰

문구, 농담, 고유 표현은 복제하지 않는다. 여러 채널에서 반복되는 구조만 편집 규칙으로 사용한다.

## 공통적으로 확인된 문법

1. 설명은 한 줄씩 흩뿌리지 않고 2~4문장의 짧은 덩어리로 이어진다.
2. 좋은 대사 장면에 들어가면 나레이션이 완전히 빠지고 배우의 반응과 대사가 사건을 진행한다.
3. 화면은 고정 길이로 자르지 않는다. 위치, 인물의 목표, 행동의 결과가 바뀌는 지점에서 장면을 닫는다.
4. 나레이션은 미래 줄거리를 예고하기보다 현재 화면의 주체, 행동, 즉각적인 목적을 말한다.
5. 빠른 리듬은 원본 장면을 10초마다 버려서 만들지 않는다. 선택한 연속 장면 안의 원래 숏 전환을 활용한다.

## 계량 결과

- 표본 중앙 컷 빈도: 분당 14.35회
- 표본 중앙 숏 길이: 2.51초
- 표본 중앙 자막 문장 길이: 15.5자
- 상위 채널은 음성이 연속되지만, 사용자 기준 영상은 말 점유율 59.6%로 대사와 침묵을 더 많이 살린다.

## Constantine V3 적용 규칙

- 후반 콜드오픈 제거. 원본 00:46부터 엄격한 시간순으로 진행한다.
- 22분을 약 30개의 자연 장면 묶음으로 구성한다.
- 장면 길이는 18~82초로 의도적으로 다르게 둔다.
- 나레이션은 11개 전환 블록만 사용한다.
- 문장 공식: `화면의 인물/대상 + 지금 하는 행동 + 당장의 목적 또는 의미`.
- 금지: 화면에 없는 미래 사실, 결말 암시, 같은 접속어 반복, 다음 영화 대사의 선요약.
- 각 나레이션은 해당 구간의 대표 프레임과 대조해 행동 일치를 확인한다.
- 가브리엘의 정체가 드러나기 전인 원본 92분 36초에서 종료한다.
