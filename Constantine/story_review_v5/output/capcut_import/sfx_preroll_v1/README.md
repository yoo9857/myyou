# Constantine narration pre-roll SFX V1

Import `constantine_sfx_preroll_stem.m4a` as one separate CapCut audio track starting at `00:00:00.000`.

- The stem contains five low-level effects only; it does not contain movie sound, narration, or outro music.
- Keep the track at 0 dB because the individual effects are already reduced and the stem applies an additional 0.85 gain.
- `sfx_preroll_timeline_v1.csv` contains the exact placements if individual WAV clips are preferred.
- `constantine_sfx_preroll_preview_v1.mp4` is a 22.645-second listening reel in this order: knife, bass omen, curiosity, neutral transition, short whoosh.
- Do not shift the narration or movie-caption tracks. The quiet effect tails intentionally overlap the first 0.15–0.28 seconds of selected narration cues.
- The existing CapCut project JSON was not modified.
