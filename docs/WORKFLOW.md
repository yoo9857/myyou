# COLONY 영화 리뷰 자동 제작 과정

## 목표

- 최종 길이: 19~25분, 기본 목표 22분
- 구성: 강한 전조 → 설정 → 사건 → 상승 → 중반 전환 → 후반 위기 → 클라이맥스 직전 종료
- 결말 정책: 최종 정체, 제거 결과, 생존 결과는 공개하지 않는다.
- 편집 리듬: 짧은 나레이션과 영화 원음 대사를 교차한다.
- 최종 편집: 자동 러프컷과 SRT를 만든 뒤 CapCut에서 마무리한다.

## 입력

- 영화 원본 MP4
- 영화에 포함된 기존 SRT
- `config.json`
- `assets/sfx/narration_preroll/`의 사용자 승인 프리롤 효과음 라이브러리
- 로그인된 Codex CLI
- ElevenLabs Starter API 키(Windows 사용자 환경 변수 `ELEVENLABS_API_KEY`)

비밀키는 문서, 코드, JSON, 채팅에 기록하지 않는다. ElevenLabs 키는 실제 Secret Key인 `sk_...` 형식만 사용한다.

## 전체 흐름

0. 참고 영상 학습 게이트
   - 자막·수치·한계를 `work/references/`에 기록하고 원문 표현은 생성 입력에서 제외한다.
   - 관찰은 바로 규칙이 되지 않는다. 근거·적용 범위·롤백 조건을 가진 후보로 만든 뒤 짧은 미리보기와 사용자 승인을 통과해야 한다.
   - 승인 규칙만 `work/references/learning_registry.json`에 `approved`로 보관한다.
   - `python scripts/validate_reference_learning.py work/references/learning_registry.json`이 실패하면 새 대본을 생성하지 않는다.
1. `python pipeline.py analyze`
   - 영상 길이와 스트림 정보를 확인한다.
   - 기존 SRT를 3분 단위 사건 패킷으로 나눈다.
   - 나레이션을 넣을 수 있는 대사 공백과 대표 화면을 만든다.
2. `python pipeline.py plan`
   - 이야기 지도와 19~25분 편집표를 만든다.
   - 이 단계에서는 컷, 원음 보존 여부, 스토리 비트만 우선 결정한다.
3. `python narration_pass.py generate`
   - 기존 편집표의 컷을 변경하지 않고 나레이션만 별도로 심사한다.
   - 1차 인과 브리지, 2차 사람다운 연결, 3차 건조한 유머의 세 버전 패스로 발전시킨다.
   - 2차 패스에서는 `docs/NARRATION_STYLE_GUIDE.md`에 따라 장면별로 긴 원음 호흡형, 마이크로 교차형, 무해설 보존형을 선택한다.
   - 필요 없는 해설은 삭제하고, 필요한 문장은 보통 2~5초 길이로 다시 쓴다.
   - 상황과 분위기가 맞는 일부 문장에만 프리롤 효과음 ID와 0.20~0.85초 리드 시간을 지정한다.
   - 생성 프롬프트에는 학습 레지스트리의 승인 규칙만 들어가며 원본 참고 영상 문장·농담·제목은 들어가지 않는다.
   - 모든 후보에 보호 상태를 기록하고, 보호 상태가 `clear`가 아니면 효과음 선택을 금지한다.
   - 한국어 표시 문장과 Nayva용 영어 TTS 문장을 함께 생성한다.
4. `python narration_pass.py apply`
   - 검증된 나레이션을 `output/edit_plan.json`에 적용한다.
5. `python pipeline.py preflight`
   - 영화·SRT·스토리맵·승인 편집표·참고 학습 레지스트리·보이스 프로필·나레이션/SFX 게이트를 한 번에 검사한다.
   - 실패하면 렌더하지 않으며 통과 결과는 `output/WORKFLOW_PREFLIGHT_QA.json`에 기록한다.
6. `python pipeline.py render`
   - FFmpeg로 클립, 러프컷, 원음 덕킹, 타임라인을 만든다.
   - SRT로 프리롤 대사 충돌을 검사하고, 효과음 꼬리가 나레이션 아래 0.10~0.30초만 남는지 계산한다.
   - 선택 효과음이 있으면 CapCut 타임라인 0초용 `sfx_preroll_stem.m4a`와 `SFX_PREROLL_QA.json`을 자동 생성한다.
7. ElevenLabs TTS
   - 모델: `eleven_v3`
   - 승인 프로필: `voice_profiles/colony_original_normal.json`
   - Voice ID: `Vuo6zmtjWmlDbzqgIDos`
   - 보이스 설정: 공급자 기본값(별도 안정성·스타일·속도 지시 금지)
   - 출력: 승인 샘플과 같은 무음 제거·음량 보정 후 48kHz mono 192kbps MP3
   - 전체 생성 전 한 줄을 먼저 승인받고, 문장이 같은 승인 샘플은 재생성하지 않고 그대로 복사한다.
   - manifest의 문장과 음성 프로필 SHA-256이 일치하지 않는 기존 MP3는 재사용하지 않는다.
8. CapCut
   - 러프컷, 영화 자막, 나레이션 오디오/자막을 가져온다.
   - 효과, 음악, 자막 디자인, 미세 컷 조정을 마무리한다.
   - 영화 대사는 `dialogue-modern.json`, 나레이션은 `narration-modern.json`을 사용해 별도 트랙으로 가져온다.
   - 선택된 효과음은 `SFX_PREROLL` 별도 오디오 트랙에 두고 `sfx_timeline.csv`의 시작 시간을 따른다.
   - 통합 SRT는 검토용으로만 유지하고 CapCut에 중복으로 가져오지 않는다.
9. 엔딩 아웃트로
   - 스포일러 컷이 아닌 통쾌한 액션 장면을 16.6초 사용한다.
   - 영화 원음은 완전히 음소거하고 Nayva 나레이션과 크레딧 음악만 사용한다.
   - 크레딧 음악은 `The Final Resolve.mp3`의 15초 지점부터 사용한다.
   - 마지막 약 3초는 화면을 어둡게 하고 `LIKE + SUBSCRIBE` 카드를 표시한다.
   - CapCut에서는 `output/capcut_import/outro_v5/colony_outro_v5.mp4`를 본편 끝에 배치하고 한국어 SRT를 가져온다.

## 나레이션 품질 기준

- 첫 문장은 화면과 즉시 연결되는 전조 한 줄만 사용한다.
- 설명보다 `상황 규정 → 다음 위험 암시 → 원음 대사` 순서를 우선한다.
- 한 번에 한 가지 정보만 전달한다.
- 같은 사건을 영화 대사가 곧 말한다면 나레이션에서 먼저 설명하지 않는다.
- 질문은 영상 전체에서 최대 두 번만 사용한다.
- `결국`, `마침내`처럼 결과를 미리 확정하는 표현은 바로 화면에 나타날 때만 쓴다.
- 나레이션 뒤 0.12초 후 기존 영화 자막과 원음이 복귀한다.
- 강한 액션, 감정 대사, 반전 공개 장면은 나레이션 없이 둔다.
- 두 나레이션 블록이 연속되면 다음에는 의미 있는 영화 대사, 반응, 행동 또는 효과음 구간을 우선 둔다.
- 오프닝은 설명 밀도를 높이고, 중반은 영화 대사 중심으로 낮추며, 위기 진입부에서 필요한 인과만 다시 압축한다.
- 나레이터가 빠진 구간이 사건을 진행하지 않는 정적이면 줄이고, 좋은 원음 대사나 시각적 행동이면 유지한다.
- 짧고 유용한 영화 대사가 연속되는 장면은 `한 줄 해설 → 영화 대사 → 반응 → 다음 브리지`로 교차한다.
- 전체 영상에 하나의 나레이션 밀도를 강제하지 않고, 장면별 대사 품질과 극적 기능에 따라 프로필을 바꾼다.

## 나레이션 프리롤 효과음

- 기본값은 `none`이며 19~25분 리뷰 전체에서 최대 8회만 사용한다.
- 효과음은 검증된 대사 공백에서 나레이션보다 0.20~0.85초 먼저 시작한다.
- 조용한 꼬리만 나레이션 첫 0.10~0.30초 아래에 겹치고, 말의 첫 자음을 가리면 안 된다.
- 편집용 파일은 피크 약 `-16~-14 dBFS`로 미리 낮춰 두며, 실제 믹스에서는 나레이션보다 10~14dB 아래로 들리게 한다.
- 강한 영화 대사를 효과음 때문에 더킹하지 않는다. 대사가 중요한 구간은 효과음을 제거한다.
- 죽음, 슬픔, 고백, 발견의 보상, 반전 공개, 공포의 결산, 전투 중에는 사용하지 않는다.
- 같은 효과음은 최소 90초 뒤에 재사용하고, 어떤 효과음끼리도 최소 25초 간격을 둔다.
- 상황별 기본 선택:
  - `danger_knife`: 무기 위협, 포식자 등장, 큰 위험 상승. 전체 1회 이하.
  - `short_whoosh`: 빠른 오프닝 전환, 급한 장면 인계.
  - `bass_omen`: 불길한 설정, 막 전환, 위기 상승, 클라이맥스 진입.
  - `neutral_transition`: 시간·장소 이동, 평범한 인과 브리지.
  - `curiosity_sting`: 단서, 수상한 물건, 아직 풀리지 않은 의문.
- 프리롤 타이밍은 나레이션 자막·음성 시작에도 동일하게 적용하고, 영화 자막은 나레이션 종료 후 0.12초 뒤 재개한다.
- 기본 렌더는 효과음을 굽지 않고 CapCut 별도 트랙으로 인계한다. 러프컷 청취용으로 `render_bake_sfx_preroll=true`를 사용했다면 CapCut에서 같은 효과음을 다시 넣지 않는다.
- 코드 게이트는 제공 SRT의 대사가 프리롤 구간과 조금이라도 겹치면 렌더를 중단한다.
- 효과음 길이에서 리드 시간을 뺀 값이 0.10~0.30초가 아니면 렌더를 중단한다.
- 자동 믹스는 기본 `narration_sfx_mix_gain=0.85`, `amix normalize=0`, `alimiter=0.891251`을 사용한다.
- CapCut에서는 타임라인 0초에 `sfx_preroll_stem.m4a` 하나만 올린다. 스템과 개별 WAV를 동시에 사용하지 않는다.

## 생성물

- `work/analysis/`: 이야기 지도와 분석 데이터
- `output/edit_plan.json`: 현재 적용 편집표
- `output/narration_script_v5.json`: 구조화된 나레이션 심사 결과
- `output/narration_script_v5.md`: 사람이 검토하기 쉬운 대본표
- `output/edit_plan_v5_narration.json`: 개선 나레이션이 적용된 편집표
- `output/rough_cut_*.mp4`: 자동 편집본
- `output/capcut_import/`: CapCut 인계 묶음
- `output/capcut_import/sfx_timeline.csv`: 선택된 프리롤 효과음의 타임라인 시작점
- `output/capcut_import/sfx_preroll/`: 실제 사용 효과음과 manifest
- `output/capcut_import/sfx_preroll/sfx_preroll_stem.m4a`: 전체 길이의 단일 CapCut 효과음 스템
- `output/capcut_import/sfx_preroll/SFX_PREROLL_QA.json`: 사용 수, 간격, 꼬리 겹침, 믹스 방식 검증
- `output/capcut_import/outro_v5/`: 최종 엔딩 영상, 한국어 자막, Nayva 음성, 대본

## 다른 영화에 재사용

- 사용자 전역 Codex 스킬: `%USERPROFILE%\.codex\skills\edit-movie-review`
- 새 영화 리뷰 요청 시 `$edit-movie-review`를 사용하면 이 프로젝트에서 확정한 전체 흐름과 품질 기준을 다시 불러온다.
- 영화별로 바꾸는 값은 원본 파일, SRT, 스포일러 경계, 장면 선택, 대본, 제목뿐이다.
- 19~25분 구성, 결말 보호, 승인 프로필 기반의 짧은 나레이션, 정확한 자막 재매핑, CapCut 인계, 짧은 엔딩 구조는 기본값으로 유지한다.

## 지속 학습과 승격

- 순서는 `관찰 → 수치화 → 후보 규칙 → 짧은 미리보기 → 사용자 승인 → 공용 규칙 승격 → 회귀검사`다.
- 새 참고 영상의 밀도를 기존 참고 영상과 평균내지 않는다. 각 스토리 단위에서 긴 원음 호흡형, 마이크로 교차형, 무해설 보존형 중 하나를 선택한다.
- 새 규칙이 영화 대사 선요약, 3개 연속 나레이션, 보호 장면 침범, 효과음 중복, 결말 누설을 만들면 즉시 거절하고 직전 승인 규칙으로 돌아간다.
- 작품별 성공 사례는 수치와 QA를 남긴 뒤 공용 규칙으로 승격한다. 취향만으로 판단한 변경은 작품 로컬 설정에만 둔다.

## 완료 정의

- 스토리맵과 모든 섹션이 승인 상태이며 필수 사건 누락이 없다.
- 19~25분, 결말 보호, 연속 나레이션 최대 2개를 통과한다.
- 영화 대사·나레이션 자막 겹침 0개이며 나레이션 뒤 영화 자막이 복귀한다.
- 승인 음성 프로필·문장·해시·후처리 기록이 일치한다.
- 효과음은 승인 manifest, 대사 공백, 보호 상태, 간격, 꼬리 겹침, 음량 게이트를 모두 통과한다.
- CapCut에는 영화 대사 자막 1트랙, 리뷰 자막 1트랙, 리뷰 음성 1트랙, 필요 시 SFX 스템 1트랙만 존재한다.
- 최종 영상·미리보기·타임라인·QA·CapCut 인계본이 생성되고 기존 원본과 이전 승인본은 보존된다.

## 보안 및 운영

- API 키를 출력하거나 파일에 하드코딩하지 않는다.
- Voice Library 음성은 계정의 My Voices에 저장한다.
- 공개 라이브러리 음성은 제공자가 제거할 수 있으므로 notice period를 확인한다.
- 외부 참고 영상은 문장을 복제하지 않고 편집 리듬과 구조만 추출한다.
