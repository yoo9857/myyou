# CapCut 자막 디자인 시스템

## 디자인 방향

- 현대적인 산세리프 글꼴 `Noto Sans KR`을 사용한다.
- 과한 애니메이션, 두꺼운 색상 박스, 무지개색 전환을 피한다.
- 영화 대사와 리뷰 나레이션은 별도 트랙과 별도 SRT로 관리한다.
- 16:9 화면의 인물 얼굴과 영화 자체 자막 영역을 가리지 않도록 하단 안전 영역을 유지한다.

## 영화 원대사

- 프리셋: `styles/capcut/dialogue-modern.json`
- 파일: `output/capcut_import/movie_captions.srt`
- 색상: 뉴트럴 화이트 `#F7F7F5`
- 크기: 5.0
- 위치: 하단 `y=-0.80`
- 표현: 얇고 선명한 검정 외곽선과 부드러운 그림자
- 목적: 영화 화면을 방해하지 않고 빠르게 읽히는 시네마 자막

## 리뷰 나레이션

- 프리셋: `styles/capcut/narration-modern.json`
- 파일: `output/capcut_import/narration.srt`
- 색상: 따뜻한 아이보리 골드 `#FFF0C2`
- 크기: 6.0
- 위치: 원대사보다 위쪽 `y=-0.64`
- 표현: 조금 더 강한 외곽선과 그림자
- 목적: 영화 대사가 아니라 리뷰어의 해설임을 즉시 구분

## 적용 원칙

- `captions_combined.srt`는 검토·내보내기용으로만 유지하고 CapCut에는 직접 가져오지 않는다.
- 영화 원대사와 나레이션 SRT를 각각 한 번만 가져온다.
- 기존 중복 자막 트랙은 백업 후 제거한다.
- 자막 스타일 변경은 시간값이나 문장 내용에 영향을 주지 않아야 한다.
- 적용 후 처음, 중간, 마지막 구간에서 두 트랙의 위치·색상·동기화를 확인한다.
