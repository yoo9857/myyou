# Reviewer storytelling patterns

## Evidence base

The local reference corpus contains six Korean movie-review videos. Treat measurements as observations, not universal targets.

| Profile | References | Speech coverage | Median speech gap | Median shot |
|---|---|---:|---:|---:|
| Immersive scene-led | Movie 101, Movie Trip samples | 44.7–59.6% | 3.28–6.33s | 1.17–3.04s |
| Narration-dense | G Movie, GoMong, B Man | 93.5–97.7% | 0.76–1.27s | 1.20–2.88s |

Median caption length across the corpus is about 14 Korean characters. Channels vary strongly in cut rate, so fixed clip length is not a quality signal.

## Default SSS profile

Combine three strengths without imitating any channel's language:

- Use the immersive profile for emotional scenes, discoveries, comedy, action payoffs, and suspense.
- Use narration-dense clarity only to compress travel, repeated exposition, or rules the audience cannot infer.
- Add thematic analysis at act turns, after the film has supplied evidence.

## Repeating high-quality pattern

Build each story unit as:

1. **Question** — establish what the audience now wants to know.
2. **Cause** — show the event that forces the next action.
3. **Experience** — let original dialogue, performance, and sound carry the scene.
4. **Bridge** — state time, place, destination, or an already-known motive during a natural transition.
5. **Payoff** — show the discovery or reversal without narrating it first.
6. **Expansion** — turn the answer into a larger question.

## Narration depth ladder

Use the lowest sufficient level:

1. `orient`: who, where, and current action.
2. `causal_bridge`: completed cause and current destination.
3. `rule_clarify`: a world rule already demonstrated.
4. `character_subtext`: motive or denial supported by prior behavior.
5. `stakes`: what can now be lost, based on known facts.
6. `reflection`: theme after a complete act, never before the scene earns it.

Do not make every line analytical. Richness comes from placing deeper lines at meaningful turns, not from increasing narration density.

## Failure signatures

- Summary before experience: narration states a payoff before the audience sees it.
- Missing cause: a character acts intensely without the inciting event being shown.
- Mechanical sampling: every clip has similar length regardless of dramatic function.
- Explanation echo: narration repeats the next dialogue line.
- Commentary confetti: isolated narration lines interrupt scenes without changing understanding.
- False depth: thematic claims appear before character behavior supports them.
